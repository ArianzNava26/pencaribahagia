# Happiness Version Finder 🌟

A simple and interactive Python program designed to spread positive affirmations. This program will ask for your name and the top 3 positive things you love most in life, and then weave them into a meaningful message about your own version of true happiness.

## 🚀 Features

* **Interactive:** A Command Line Interface (CLI) based program that asks for direct user input.
* **Personalized:** The output is tailored specifically to the name and the favorite things provided by the user.
* **Positive Message:** A gentle reminder that happiness is often connected to how we can help others using the things we love.

## 📋 Prerequisites

To run this script, you only need to have **Python 3.x** installed on your computer. You can download it from [python.org](https://www.python.org/).

## 🛠️ How to Run

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/ArianzNava26/pencaribahagia.git
   ```

2. Open your terminal or command prompt.

3. Navigate to the directory where the repository was cloned.

4. Run the following command to start the program (make sure to run `intro.py` as it is the main script):
   ```bash
   python intro.py
   ```
